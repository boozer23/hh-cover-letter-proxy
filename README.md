# hh-cover-letter-proxy

Бэкенд для расширения, которое генерирует сопроводительное письмо под конкретную
вакансию на hh.ru. Прокси прячет ключ Groq (в браузер он не попадает), просит
модель написать письмо по профилю кандидата и обрезает типичные штампы на выходе.

## Как работает

Расширение отправляет текст вакансии и профиль кандидата на `/generate`.
Прокси добавляет ключ Groq, дёргает модель `llama-3.3-70b-versatile`, отрезает
шаблонную концовку вида «эти навыки могут быть полезны для...» и возвращает письмо.
Ключ живёт только в переменной окружения на сервере.

## Эндпоинты

    POST /generate   { vacancy, profile } -> { letter }
    GET  /health     -> { status: "ok" }

Rate-limit: 20 запросов в час на IP (в памяти процесса).

## Запуск локально

    python3 -m pip install -r requirements.txt
    export GROQ_API_KEY=твой_ключ
    uvicorn main:app --reload

Проверка: `curl localhost:8000/health`

## Docker

    export GROQ_API_KEY=твой_ключ
    docker compose up --build

## Деплой

Задеплоено на Render как Docker web service. Ключ Groq — в переменных окружения
сервиса. `Dockerfile` слушает порт из `$PORT`, который выдаёт Render.

## Дальше
